# Tabox Chrome Web Store — First Screenshot Concepts

All four concepts are 1280×800 PNGs. They use the real Tabox 4.2.2 full-page UI, the canonical extension icon, **Comfortaa for every marketing-text element**, and the current purple–blue–orange brand palette. The `Tabox` title is a single solid color; `Organize Beautifully` sits directly beneath it beside the icon and carries the purple → blue → orange gradient.

The current variants use quiet CSS gradient fields with only a restrained corner glow. Earlier generated background studies remain in `backgrounds/` as optional source material but are intentionally hidden in the final compositions.

## Shared copy

- Logo-lockup slogan: `Organize Beautifully`
- Headline: `Save your tabs. Clear your mind.`
- Supporting line: `Turn tab overload into organized collections you can reopen in one click.`
- Feature chips: `Save` · `Organize` · `Reopen`
